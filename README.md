# Mario Kart Phonics (Vite + React)

An early-learning spelling race where kids pick the correct spelling of spoken words to move their kart forward, earn power-ups, and compete against AI rivals.

## Local setup

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Open the printed localhost URL to play.
4. Run `npm run build` to verify a production build, or `npm run lint` for static checks.

## One-click StackBlitz preview

## Scripts

- `npm run dev` – Vite dev server with hot reload
- `npm run build` – production build
- `npm run lint` – ESLint check
